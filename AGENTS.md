# SRL League System AI Agent Rules

This file acts as a router for all AI coding assistants (Antigravity, Kilo Code, OpenCode, etc.). 

## Core Directives
1. **Always read detailed rules**: For specific workflows, you MUST read `.agents/rules/workflow.md`.
2. **Spec-Driven Development**: No feature implementation can begin without an approved spec in `docs/specs/`. 
3. **Spec Archiving**: Once a spec is fully implemented, you MUST move the spec file to `docs/specs/archive/`.
4. **Task Tracking**: Always update `TODO.md` when starting or completing a task.
5. **Changelog**: Always document your additions, changes, and deprecations under the `[Unreleased]` section of `CHANGELOG.md` when finishing a task.
